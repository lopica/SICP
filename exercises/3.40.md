# Bài tập 3.40

Đưa ra tất cả các giá trị có thể của `x` khi thực thi:

```lisp
(define x 10)
(parallel-execute
  (lambda () (set! x (* x x)))
  (lambda () (set! x (* x x x))))
```

Những giá trị nào còn có thể xảy ra nếu thêm tuần tự hóa?

```lisp
(define x 10)
(define s (make-serializer))
(parallel-execute
  (s (lambda () (set! x (* x x))))
  (s (lambda () (set! x (* x x x)))))
```

---

**Không tuần tự hóa:**

Gọi $P_1$: `(set! x (* x x))` và $P_2$: `(set! x (* x x x))`. Mỗi tiến trình có 3 bước: đọc lần 1, đọc lần 2 (thêm lần 3 cho $P_2$), ghi. Với $x = 10$ ban đầu, các xen kẽ khả dĩ cho ra:

- $P_1$ chạy xong trước $P_2$: `x = 100`, rồi `x = 100*100*100 = 1,000,000` → **1000000**
- $P_2$ chạy xong trước $P_1$: `x = 1000`, rồi `x = 1000*1000 = 1,000,000` → **1000000**
- $P_1$ đọc $x=10$ hai lần (kết quả 100), $P_2$ đọc $x=10$ ba lần (kết quả 1000), $P_1$ ghi 100, $P_2$ ghi 1000 → **1000**
- $P_2$ đọc $x=10$ ba lần (kết quả 1000), $P_1$ đọc $x=10$ hai lần (kết quả 100), $P_2$ ghi 1000, $P_1$ ghi 100 → **100**
- $P_1$ đọc 10 lần 1, $P_2$ đọc 10 ba lần, $P_1$ đọc 10 lần 2, $P_1$ ghi 100, $P_2$ ghi 1000 → **1000**
- $P_1$ đọc 10 lần 1, $P_2$ chạy xong (ghi 1000), $P_1$ đọc 1000 lần 2, $P_1$ ghi `10*1000 = 10000` → **10000**
- $P_2$ đọc 10 lần 1, $P_1$ chạy xong (ghi 100), $P_2$ đọc 100 lần 2, đọc 100 lần 3, ghi `10*100*100 = 100000` → **100000**
- Và các biến thể khác tương tự.

Các giá trị có thể: **100, 1000, 10000, 100000, 1000000**.

**Có tuần tự hóa:**

Khi cả hai được tuần tự hóa bởi cùng một _bộ tuần tự hóa_ `s`, chúng không thể xen kẽ nhau. Chỉ còn hai khả năng:

- $P_1$ chạy xong trước $P_2$: `x = 10*10 = 100`, rồi `x = 100*100*100 = 1,000,000` → **1000000**
- $P_2$ chạy xong trước $P_1$: `x = 10*10*10 = 1000`, rồi `x = 1000*1000 = 1,000,000` → **1000000**

Với tuần tự hóa, kết quả duy nhất có thể là: **1000000**.
