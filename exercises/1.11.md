# Bài tập 1.11

Một hàm `f` được định nghĩa bởi quy tắc: $f(n) = n$ nếu $n < 3$, và $f(n) = f(n-1) + 2f(n-2) + 3f(n-3)$ nếu $n \ge 3$. Hãy viết một quy trình tính `f` bằng một tiến trình đệ quy. Hãy viết một quy trình tính `f` bằng một tiến trình lặp.

---

**Tiến trình đệ quy** — dịch trực tiếp định nghĩa toán học:

```lisp
(define (f n)
  (if (< n 3)
      n
      (+ (f (- n 1))
         (* 2 (f (- n 2)))
         (* 3 (f (- n 3))))))
```

**Tiến trình lặp** — ta giữ ba biến trạng thái `a`, `b`, `c` lần lượt đại diện cho ba giá trị liên tiếp $f(i-1)$, $f(i-2)$, $f(i-3)$, khởi tạo bằng $f(2)=2$, $f(1)=1$, $f(0)=0$, rồi đẩy dần về phía trước cho đến khi `count` chạm `2`:

```lisp
(define (f n)
  (if (< n 3)
      n
      (f-iter 2 1 0 n)))

(define (f-iter a b c count)
  (if (= count 2)
      a
      (f-iter (+ a (* 2 b) (* 3 c)) 
              a 
              b 
              (- count 1))))
```

Kiểm tra nhanh: `f(3) = f(2) + 2·f(1) + 3·f(0) = 2 + 2 + 0 = 4`, và `f(4) = f(3) + 2·f(2) + 3·f(1) = 4 + 4 + 3 = 11`. Cả hai quy trình đều cho `(f 3)` ⇒ `4`, `(f 4)` ⇒ `11`.
