# Bài tập 3.58

Hãy giải thích **dòng chảy** được tính bởi **quy trình** sau:

```lisp
(define (expand num den radix)
  (cons-stream
   (quotient (* num radix) den)
   (expand (remainder (* num radix) den) den radix)))
```

(`quotient` là **quy trình** nguồn trả về phần nguyên của phép chia hai số nguyên.) Các phần tử liên tiếp được sinh ra bởi `(expand 1 7 10)` là gì? Còn `(expand 3 8 10)` thì sao?

---

**Quy trình** `expand` sinh ra các chữ số trong khai triển thập phân (hoặc theo cơ số `radix`) của phân số `num/den`.

Mỗi bước: nhân `num` với `radix`, lấy phần nguyên chia `den` — đó là chữ số tiếp theo; phần dư trở thành `num` cho bước sau.

**Với `(expand 1 7 10)`:**

- Bước 1: `quotient(1*10, 7) = quotient(10, 7) = 1`; dư `10 - 7 = 3`
- Bước 2: `quotient(3*10, 7) = quotient(30, 7) = 4`; dư `30 - 28 = 2`
- Bước 3: `quotient(2*10, 7) = quotient(20, 7) = 2`; dư `20 - 14 = 6`
- Bước 4: `quotient(6*10, 7) = quotient(60, 7) = 8`; dư `60 - 56 = 4`
- Bước 5: `quotient(4*10, 7) = quotient(40, 7) = 5`; dư `40 - 35 = 5`
- Bước 6: `quotient(5*10, 7) = quotient(50, 7) = 7`; dư `50 - 49 = 1`
- Bước 7: quay lại `num = 1` → lặp lại

Kết quả: $1, 4, 2, 8, 5, 7, 1, 4, 2, 8, 5, 7, \ldots$ — chính là khai triển thập phân của $1/7 = 0.\overline{142857}$.

**Với `(expand 3 8 10)`:**

- Bước 1: `quotient(30, 8) = 3`; dư `30 - 24 = 6`
- Bước 2: `quotient(60, 8) = 7`; dư `60 - 56 = 4`
- Bước 3: `quotient(40, 8) = 5`; dư `40 - 40 = 0`
- Bước 4: `quotient(0, 8) = 0`; dư `0`
- Bước 5: cứ thế `0, 0, 0, ...`

Kết quả: $3, 7, 5, 0, 0, 0, \ldots$ — chính là khai triển thập phân của $3/8 = 0.375$.
