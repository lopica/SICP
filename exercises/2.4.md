# Bài tập 2.4

Đây là một cách biểu diễn cặp giá trị bằng quy trình thay thế. Với cách biểu diễn này, hãy xác nhận rằng `(car (cons x y))` cho ra `x` với bất kỳ đối tượng `x` và `y` nào.

```lisp
(define (cons x y) 
  (lambda (m) (m x y)))

(define (car z) 
  (z (lambda (p q) p)))
```

Định nghĩa tương ứng của `cdr` là gì? (Gợi ý: Để xác nhận cách này hoạt động, hãy sử dụng mô hình thay thế ở mục 1.1.5.)

---

Dùng mô hình thay thế để tính `(car (cons x y))`:

```lisp
(car (cons x y))
(car (lambda (m) (m x y)))
((lambda (m) (m x y)) (lambda (p q) p))
((lambda (p q) p) x y)
x
```

Tại bước cuối, lambda `(lambda (p q) p)` được áp dụng lên `x` và `y`, trả về tham số đầu tiên — tức là `x`. Như vậy `(car (cons x y))` đúng là `x`.

Bằng phép suy luận tương tự, `cdr` cần chọn tham số thứ hai, tức dùng `(lambda (p q) q)`:

```lisp
(define (cdr z)
  (z (lambda (p q) q)))
```

Kiểm tra:

```lisp
(cdr (cons x y))
(cdr (lambda (m) (m x y)))
((lambda (m) (m x y)) (lambda (p q) q))
((lambda (p q) q) x y)
y
```

Kết quả là `y` như mong đợi.
