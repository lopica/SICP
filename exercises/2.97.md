# Bài tập 2.97

a. Cài đặt quy trình `reduce-terms` thực hiện rút gọn tử số và mẫu số xuống dạng tối giản. Quy trình nhận hai danh sách hạng tử `n` và `d` làm đối số và trả về danh sách `nn`, `dd` là `n` và `d` sau khi chia cho GCD của chúng. Dùng GCD nguyên nguyên thủy từ bài tập 2.96b. Để kiểm tra:

```lisp
(define p1 (make-polynomial 'x '((1 1)(0 1))))
(define p2 (make-polynomial 'x '((3 1)(0 -1))))
(define p3 (make-polynomial 'x '((1 1))))
(define p4 (make-polynomial 'x '((2 1)(0 -1))))

(define rf1 (make-rational p1 p2))
(define rf2 (make-rational p3 p4))

(add rf1 rf2)
```

Kiểm tra kết quả bằng cách rút gọn tay.

b. Định nghĩa `reduce-poly` tương tự `add-poly` để gọi `reduce-terms`. Cài đặt vào hệ thống tổng quát với tên `reduce`. Cuối cùng, định nghĩa lại gói số hữu tỉ để dùng `reduce` thay vì `gcd`:

```lisp
(define (make-rat n d)
  (let ((g (reduce n d)))
    (cons (div n (car g))
          (div d (cadr g)))))
```

Và kiểm tra lại bài toán ở đầu mục bằng ví dụ từ bài tập 2.93.

---

**Phần a.** Cài đặt `reduce-terms`:

```lisp
(define (reduce-terms n d)
  (let* ((g (gcd-terms n d))
         (nn (car (div-terms n g)))
         (dd (car (div-terms d g)))
         ;; chuẩn hóa dấu: mẫu số luôn dương
         (denom-coeff (coeff (first-term dd)))
         (sign (if (< denom-coeff 0) -1 1))
         (nn-norm (if (= sign -1)
                      (negate-terms nn)
                      nn))
         (dd-norm (if (= sign -1)
                      (negate-terms dd)
                      dd)))
    (list nn-norm dd-norm)))
```

**Phần b.** Cài đặt `reduce-poly` và đăng ký:

```lisp
(define (reduce-poly p1 p2)
  (if (same-variable? (variable p1) (variable p2))
      (let ((result (reduce-terms (term-list p1)
                                  (term-list p2))))
        (list (make-poly (variable p1) (car result))
              (make-poly (variable p1) (cadr result))))
      (error "Polys not in same var: REDUCE-POLY"
             (list p1 p2))))

(put 'reduce '(polynomial polynomial)
     (lambda (p1 p2)
       (let ((result (reduce-poly p1 p2)))
         (list (tag (car result))
               (tag (cadr result))))))

(put 'reduce '(scheme-number scheme-number)
     (lambda (n d)
       (let ((g (gcd n d)))
         (list (/ n g) (/ d g)))))

(define (reduce n d) (apply-generic 'reduce n d))
```

Cập nhật `make-rat`:

```lisp
(define (make-rat n d)
  (let ((g (reduce n d)))
    (cons (div n (car g))
          (div d (cadr g)))))
```

Kiểm tra: `rf1 = (x+1)/(x^3-1)` và `rf2 = x/(x^2-1) = x/((x-1)(x+1))`.

$(x+1)/(x^3-1) + x/(x^2-1)$

$= (x+1)/((x-1)(x^2+x+1)) + x/((x-1)(x+1))$

Mẫu số chung là $(x-1)(x+1)(x^2+x+1) = (x^2-1)(x^2+x+1)$:

$= (x+1)^2/\text{LCD} + x(x^2+x+1)/\text{LCD}$

$= ((x^2+2x+1) + (x^3+x^2+x))/\text{LCD}$

$= (x^3 + 2x^2 + 3x + 1) / ((x^2-1)(x^2+x+1))$

Sau khi rút gọn bằng `reduce`, ta thu được kết quả đúng dạng tối giản.
