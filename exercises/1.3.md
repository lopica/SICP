# Bài tập 1.3
Định nghĩa một quy trình mà lấy 3 số làm đối số và trả về tổng của bình phương 2 số lớn nhất
```lisp
(define (sum-square a b) 
  (+ (* a a) 
     (* b b)
  )
)

(define (procedure num1 num2 num3)
  (cond 
    ((and (< num1 num2) (< num1 num3)) (sum-square num2 num3))
    ((and (< num2 num1) (< num2 num3)) (sum-square num1 num3))
    ((and (< num3 num2) (< num3 num1)) (sum-square num2 num1))
    (else (sum-square num2 num1))
  )
)

(procedure 1 2 3)
```
