# Bài tập 1.18

Dựa trên kết quả của Bài tập 1.16 và Bài tập 1.17, hãy đưa ra một quy trình tạo ra một **tiến trình lặp** để nhân hai số nguyên bằng cách dùng phép cộng, nhân đôi và chia đôi, với số bước logarithmic.

---

Áp dụng kỹ thuật _lượng bất biến_ từ Bài tập 1.16 vào bài toán nhân: duy trì biến tích lũy `c` sao cho `a * b + c` không đổi qua từng bước.

- Nếu `b` chẵn: thay $(a, b, c)$ bằng $(2a, b/2, c)$ — lượng bất biến giữ nguyên vì $(2a) \times (b/2) + c = a \times b + c$.
- Nếu `b` lẻ: thay $(a, b, c)$ bằng $(a, b-1, c+a)$ — lượng bất biến giữ nguyên vì $a \times (b-1) + (c+a) = a \times b + c$.
- Khi `b = 0`: trả về `c` (vì $a \times 0 + c = c$).

```lisp
(define (double x) (+ x x))
(define (halve x) (/ x 2))

(define (even? n)
  (= (remainder n 2) 0))

(define (fast-mult a b)
  (fast-mult-iter a b 0))

(define (fast-mult-iter a b c)
  (cond ((= b 0)
         c)
        ((even? b)
         (fast-mult-iter (double a) (halve b) c))
        (else
         (fast-mult-iter a (- b 1) (+ c a)))))
```

Tiến trình lặp, cần $\Theta(\log b)$ bước và $\Theta(1)$ không gian.
