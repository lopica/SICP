# Bài tập 2.94

Dùng `div-terms` để cài đặt quy trình `remainder-terms` và dùng nó để định nghĩa `gcd-terms` như sau:

```lisp
(define (gcd-terms a b)
  (if (empty-termlist? b)
      a
      (gcd-terms b (remainder-terms a b))))
```

Bây giờ hãy viết quy trình `gcd-poly` tính **ước số chung lớn nhất** của hai đa thức. Cài đặt nó vào hệ thống bằng cách cài một quy trình `greatest-common-divisor` tổng quát hoạt động với cả số nguyên thông thường lẫn đa thức. Để kiểm tra kết quả, hãy thử:

```lisp
(define p1 (make-polynomial 'x '((4 1)(3 -1)(2 -2)(1 2))))
(define p2 (make-polynomial 'x '((3 1)(1 -1))))
(greatest-common-divisor p1 p2)
```

rồi đối chiếu với kết quả mong đợi bằng cách tính tay.

---

Trước tiên cài đặt `remainder-terms`:

```lisp
(define (remainder-terms a b)
  (cadr (div-terms a b)))
```

Rồi `gcd-terms`:

```lisp
(define (gcd-terms a b)
  (if (empty-termlist? b)
      a
      (gcd-terms b (remainder-terms a b))))
```

Và `gcd-poly`:

```lisp
(define (gcd-poly p1 p2)
  (if (same-variable? (variable p1) (variable p2))
      (make-poly (variable p1)
                 (gcd-terms (term-list p1)
                            (term-list p2)))
      (error "Polys not in same var: GCD-POLY"
             (list p1 p2))))
```

Đăng ký `greatest-common-divisor` tổng quát:

```lisp
(put 'greatest-common-divisor '(polynomial polynomial)
     (lambda (p1 p2) (tag (gcd-poly p1 p2))))

(put 'greatest-common-divisor '(scheme-number scheme-number)
     (lambda (a b) (tag (gcd a b))))

(define (greatest-common-divisor a b)
  (apply-generic 'greatest-common-divisor a b))
```

Kiểm tra tay: $p_1 = x^4 - x^3 - 2x^2 + 2x = x(x^3 - x^2 - 2x + 2) = x(x-1)(x^2-2)$ và $p_2 = x^3 - x = x(x^2-1) = x(x-1)(x+1)$. GCD là $x(x-1) = x^2 - x$. Kết quả của `greatest-common-divisor p1 p2` có thể có hệ số tỷ lệ khác nhau do phép chia nguyên (vấn đề phình hệ số sẽ được xử lý trong bài tập 2.96).
