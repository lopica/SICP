# Bài tập 3.60

Với _chuỗi lũy thừa_ biểu diễn như **dòng chảy** hệ số (xem bài tập 3.59), phép cộng hai chuỗi được cài đặt bởi `add-streams`. Hoàn chỉnh định nghĩa sau cho phép nhân hai chuỗi:

```lisp
(define (mul-series s1 s2)
  (cons-stream ⟨??⟩ (add-streams ⟨??⟩ ⟨??⟩)))
```

Bạn có thể kiểm tra **quy trình** này bằng cách xác minh rằng $\sin^2 x + \cos^2 x = 1$, dùng các chuỗi từ bài tập 3.59.

---

Nhớ lại công thức nhân hai chuỗi:

$$(a_0 + a_1 x + a_2 x^2 + \cdots)(b_0 + b_1 x + b_2 x^2 + \cdots)$$

Hệ số hằng của tích là $a_0 \cdot b_0$.

Phần còn lại (từ bậc $x$ trở lên) có thể phân tích như sau. Gọi $s_1 = a_0 + x \cdot S_1'$ và $s_2 = b_0 + x \cdot S_2'$. Khi đó:

$$s_1 \cdot s_2 = a_0 b_0 + x(a_0 \cdot S_2' + S_1' \cdot s_2)$$

Phần bậc cao hơn là: `(add-streams (scale-stream s2rest (stream-car s1)) (mul-series s1rest s2))`, trong đó `s1rest = (stream-cdr s1)`, `s2rest = (stream-cdr s2)`.

```lisp
(define (mul-series s1 s2)
  (cons-stream (* (stream-car s1) (stream-car s2))
               (add-streams (scale-stream (stream-cdr s2) (stream-car s1))
                            (mul-series (stream-cdr s1) s2))))
```

Để kiểm tra $\sin^2 x + \cos^2 x = 1$:

```lisp
(define sin2+cos2
  (add-streams (mul-series sine-series sine-series)
               (mul-series cosine-series cosine-series)))
```

Kết quả nên là **dòng chảy** `1, 0, 0, 0, ...` (hệ số của chuỗi hằng số 1).
