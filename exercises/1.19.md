# Bài tập 1.19

Có một thuật toán thú vị để tính **số Fibonacci** trong số bước logarithmic. Hãy nhớ lại phép biến đổi trạng thái trong tiến trình `fib-iter` ở mục 1.2.2: $a \leftarrow a + b$ và $b \leftarrow a$. Gọi phép biến đổi này là $T$, và chú ý rằng áp dụng $T$ liên tiếp $n$ lần từ điểm xuất phát $(1, 0)$ sẽ cho ra cặp $(\text{Fib}(n+1), \text{Fib}(n))$.

Hãy xét $T$ như là trường hợp đặc biệt khi $p = 0$ và $q = 1$ trong một họ các phép biến đổi $T_{pq}$, trong đó $T_{pq}$ biến đổi cặp $(a, b)$ theo quy tắc:

$$a \leftarrow bq + aq + ap,$$
$$b \leftarrow bp + aq.$$

Hãy chỉ ra rằng áp dụng $T_{pq}$ hai lần liên tiếp tương đương với một lần áp dụng phép biến đổi $T_{p'q'}$ cùng dạng, đồng thời tính $p'$ và $q'$ theo $p$ và $q$. Điều này cho ta cách tính bình phương các phép biến đổi một cách tường minh, để ta có thể tính $T^n$ bằng bình phương liên tiếp, giống như `fast-expt`. Hãy hoàn thiện quy trình sau, chạy trong số bước logarithmic:

```lisp
(define (fib n)
  (fib-iter 1 0 0 1 n))

(define (fib-iter a b p q count)
  (cond ((= count 0)
         b)
        ((even? count)
         (fib-iter a
                   b
                   ⟨??⟩  ; tính p'
                   ⟨??⟩  ; tính q'
                   (/ count 2)))
        (else
         (fib-iter (+ (* b q)
                      (* a q)
                      (* a p))
                   (+ (* b p)
                      (* a q))
                   p
                   q
                   (- count 1)))))
```

---

**Suy ra $p'$ và $q'$:**

Áp dụng $T_{pq}$ lần thứ nhất lên $(a, b)$:

$$a_1 = bq + aq + ap, \quad b_1 = bp + aq.$$

Áp dụng $T_{pq}$ lần thứ hai lên $(a_1, b_1)$:

$$a_2 = b_1 q + a_1 q + a_1 p = (bp + aq)q + (bq + aq + ap)q + (bq + aq + ap)p$$

$$= b(2pq + q^2) + a(p^2 + q^2) + a(2pq + q^2)$$

$$= b(2pq + q^2) + a(2pq + q^2) + a(p^2 + q^2)$$

$$b_2 = b_1 p + a_1 q = (bp + aq)p + (bq + aq + ap)q$$

$$= b(p^2 + q^2) + a(2pq + q^2)$$

So sánh với dạng chuẩn $T_{p'q'}$: $a \leftarrow bq' + aq' + ap'$ và $b \leftarrow bp' + aq'$, ta nhận ra:

$$p' = p^2 + q^2, \quad q' = 2pq + q^2.$$

Điền vào quy trình:

```lisp
(define (fib n)
  (fib-iter 1 0 0 1 n))

(define (fib-iter a b p q count)
  (cond ((= count 0)
         b)
        ((even? count)
         (fib-iter a
                   b
                   (+ (* p p) (* q q))       ; p' = p² + q²
                   (+ (* 2 p q) (* q q))     ; q' = 2pq + q²
                   (/ count 2)))
        (else
         (fib-iter (+ (* b q)
                      (* a q)
                      (* a p))
                   (+ (* b p)
                      (* a q))
                   p
                   q
                   (- count 1)))))
```

Mỗi lần `count` chẵn, ta bình phương phép biến đổi (giảm `count` một nửa); mỗi lần `count` lẻ, ta áp dụng một bước $T_{pq}$ (giảm `count` đi 1). Tổng số bước là $\Theta(\log n)$.
