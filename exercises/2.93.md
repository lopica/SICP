# Bài tập 2.93

Sửa đổi gói số hữu tỉ để dùng phép tính số học tổng quát thay cho các phép toán số học thông thường. Kiểm tra hệ thống bằng cách tạo số hữu tỉ có tử số và mẫu số là đa thức:

```lisp
(define p1 (make-polynomial 'x '((2 1)(0 1))))
(define p2 (make-polynomial 'x '((3 1)(0 1))))
(define rf (make-rational p2 p1))
```

Bây giờ hãy thêm `rf` với chính nó, dùng `add`. Bạn sẽ thấy rằng quy trình này không rút gọn phân số.

---

Ta sửa gói số hữu tỉ để dùng `add`, `sub`, `mul`, `div` tổng quát thay cho `+`, `-`, `*`, `/`:

```lisp
(define (install-rational-package)
  ;; các quy trình nội bộ
  (define (numer x) (car x))
  (define (denom x) (cdr x))
  (define (make-rat n d) (cons n d))  ; chưa rút gọn
  (define (add-rat x y)
    (make-rat (add (mul (numer x) (denom y))
                   (mul (numer y) (denom x)))
              (mul (denom x) (denom y))))
  (define (sub-rat x y)
    (make-rat (sub (mul (numer x) (denom y))
                   (mul (numer y) (denom x)))
              (mul (denom x) (denom y))))
  (define (mul-rat x y)
    (make-rat (mul (numer x) (numer y))
              (mul (denom x) (denom y))))
  (define (div-rat x y)
    (make-rat (mul (numer x) (denom y))
              (mul (denom x) (numer y))))
  ;; giao diện
  (define (tag x) (attach-tag 'rational x))
  (put 'add '(rational rational)
       (lambda (x y) (tag (add-rat x y))))
  (put 'sub '(rational rational)
       (lambda (x y) (tag (sub-rat x y))))
  (put 'mul '(rational rational)
       (lambda (x y) (tag (mul-rat x y))))
  (put 'div '(rational rational)
       (lambda (x y) (tag (div-rat x y))))
  (put 'make 'rational
       (lambda (n d) (tag (make-rat n d))))
  'done)
```

Khi thực thi `(add rf rf)` với `rf = p2/p1`, kết quả là:

$$\frac{p_2}{p_1} + \frac{p_2}{p_1} = \frac{p_2 \cdot p_1 + p_2 \cdot p_1}{p_1 \cdot p_1} = \frac{2 p_2 p_1}{p_1^2}$$

Phân số này chưa được rút gọn vì `make-rat` không gọi GCD. Bài tập 2.94 và 2.97 sẽ khắc phục điều này.
