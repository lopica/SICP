# Bài tập 1.27

Chứng minh rằng các số Carmichael được liệt kê trong chú thích 47 thực sự "đánh lừa" được phép thử Fermat. Tức là, hãy viết quy trình nhận vào một số nguyên $n$ và kiểm tra xem $a^n \equiv a \pmod{n}$ có đúng hay không với mọi $a < n$. Thử quy trình của bạn với các số Carmichael 561, 1105, 1729, 2465, 2821 và 6601.

---

```lisp
(define (square x) (* x x))

(define (expmod base exp m)
  (cond ((= exp 0) 1)
        ((even? exp)
         (remainder (square (expmod base (/ exp 2) m))
                    m))
        (else
         (remainder (* base (expmod base (- exp 1) m))
                    m))))

(define (carmichael-number? n)
  (define (try-it n a)
    (cond ((= a 1) #t)
          ((not (= (expmod a n n) a)) #f)
          (else (try-it n (- a 1)))))
  (try-it n (- n 1)))
```

Quy trình `carmichael-number?` kiểm tra tất cả các giá trị $a$ từ $n-1$ xuống đến $1$. Nếu tất cả đều thỏa $a^n \equiv a \pmod{n}$, trả về `#t`; ngay khi tìm thấy một $a$ không thỏa, trả về `#f`.

Kết quả:

```lisp
(carmichael-number? 561)   ; => #t
(carmichael-number? 1105)  ; => #t
(carmichael-number? 1729)  ; => #t
(carmichael-number? 2465)  ; => #t
(carmichael-number? 2821)  ; => #t
(carmichael-number? 6601)  ; => #t
```

Tất cả sáu số này đều vượt qua phép thử Fermat với mọi $a < n$, mặc dù chúng đều là hợp số (ví dụ $561 = 3 \times 11 \times 17$). Đây chính là lý do số Carmichael được coi là "điểm mù" của phép thử Fermat — không thể phân biệt chúng với số nguyên tố bằng thuật toán ngẫu nhiên thông thường.
