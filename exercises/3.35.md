# Bài tập 3.35

Ben Bitdiddle hướng dẫn Louis Reasoner (xem bài tập 3.34) rằng cách đúng để xây dựng ràng buộc bình phương là định nghĩa trực tiếp một ràng buộc mới, giống như `adder` và `multiplier`. Hãy hoàn thiện định nghĩa dưới đây cho **quy trình** `squarer`:

```lisp
(define (squarer a b)
  (define (process-new-value)
    (if (has-value? b)
        (if (< (get-value b) 0)
            (error "square less than 0 -- SQUARER" (get-value b))
            <alternative1>)
        <alternative2>))
  (define (process-forget-value)
    <body1>)
  (define (me request)
    <body2>)
  (connect a me)
  (connect b me)
  me)
```

---

Ta cần điền vào hai phần quan trọng:

- `<alternative1>`: khi biết `b`, tính `a = √b`.
- `<alternative2>`: khi biết `a`, tính `b = a²`.
- `<body1>`: xóa giá trị cả hai kết nối và thử lại.
- `<body2>`: điều phối thông điệp như `adder` và `multiplier`.

```lisp
(define (squarer a b)
  (define (process-new-value)
    (if (has-value? b)
        (if (< (get-value b) 0)
            (error "square less than 0 -- SQUARER" (get-value b))
            (set-value! a (sqrt (get-value b)) me))
        (if (has-value? a)
            (set-value! b (square (get-value a)) me)
            'nothing)))
  (define (process-forget-value)
    (forget-value! a me)
    (forget-value! b me)
    (process-new-value))
  (define (me request)
    (cond ((eq? request 'I-have-a-value) (process-new-value))
          ((eq? request 'I-lost-my-value) (process-forget-value))
          (else (error "Unknown request -- SQUARER" request))))
  (connect a me)
  (connect b me)
  me)
```

Ở đây `square` là **quy trình** bình phương thông thường `(define (square x) (* x x))`.

Kiểm tra cả hai chiều:

```lisp
(define A (make-connector))
(define B (make-connector))
(squarer A B)
(probe "A" A)
(probe "B" B)

; Chiều thuận: biết A, tính B
(set-value! A 4 'user)
; => Probe: B = 16

(forget-value! A 'user)

; Chiều ngược: biết B, tính A
(set-value! B 25 'user)
; => Probe: A = 5
```

Khác với `(multiplier a a b)` của Louis (xem bài tập 3.34), cách này xử lý đúng cả hai chiều vì ta kiểm tra từng kết nối một cách tường minh.
